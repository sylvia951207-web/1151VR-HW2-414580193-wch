# 1151VR-HW2 2D 跳躍遊戲

## 遊戲內容
玩家控制角色向前移動、跳過地板缺口與尖刺，到達終點。

## 操作方式
- A／←：向左移動
- D／→：向右移動
- 空白鍵：跳躍
- S／↓：快速下落

## 程式功能
- 使用 Vector2 控制角色移動與跳躍。
- 使用陣列設定移動速度。
- 碰到尖刺時角色向下墜落。
