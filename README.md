# 1151VR-HW2 2D 跳躍遊戲

## 遊戲內容
玩家控制角色向前移動、跳過地板缺口與尖刺，到達終點。

## 製作流程

1. 在 Unity 建立 2D 專案，新增角色、地板、尖刺陷阱及終點旗幟。
2. 排列地板，保留空隙作為需要跳過的漏洞。
3. 為角色加入 Rigidbody 2D 和 Box Collider 2D，為各塊地板加入 Box Collider 2D。
4. 編寫 PlayerMovement.cs，使用 Vector2 控制角色移動與跳躍，並使用陣列設定移動速度。
5. 為尖刺設定觸發範圍，讓角色碰到尖刺時停止移動並向下墜落。
6. 在 Unity 試玩，調整地板與尖刺的碰撞範圍。

## 相關操作

- 按 A 或 ←：向左移動。
- 按 D 或 →：向右移動。
- 按空白鍵：跳躍；落地後才能再次跳躍。
- 按 S 或 ↓：加速下落。
- 避開地板漏洞和尖刺，朝終點旗幟移動。

## 程式功能
- 使用 Vector2 控制角色移動與跳躍。
- 使用陣列設定移動速度。
- 碰到尖刺時角色向下墜落。
